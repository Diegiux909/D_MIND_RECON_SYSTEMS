# DKMDM
project from dron and sketches and diagrams

el compromiso principal es la creacion de un dron para el reconocimiento de espacios geograficos
Vision: inovacion, apertura de miras , busqueda de nuevas tecnologias y trabajo en equipo
Mision: Inovar en las tecnologias actuales de drones haciendo de una forma economica y accesible para todo el publico que tenga conocimiento de area tecnologica y para lo que tengan poco
Objetivo: crear un dron de bajo presupuesto para el reconocimiento del area geografica en lugares poco accesibles
